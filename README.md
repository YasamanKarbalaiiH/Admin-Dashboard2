# Admin Dashboard

A modern and responsive admin dashboard built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- Dashboard overview
- Customer management
- Product management
- Invoice management
- Profile management
- Settings
- CRUD operations
- Responsive design
- Data visualization
- Form validation
- Fake API with JSON data

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts
- React Hook Form
- Zod
- Lucide React
